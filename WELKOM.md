## 🎯 Volgende stappen

📁 Plaats je foto's in `public/images/` map:

- `client-1.jpg` t/m `client-3.jpg` - Klant foto's
- `favicon.png` - Website icoon

### 2. Configureer het contact formulier
📧 Volg de stappen in `README.md` voor EmailJS setup

### 3. Personaliseer je social media links
🔗 Update de links in `public/index.html`

### 4. Deploy naar Firebase
🚀 Volg de instructies in `README.md` of `QUICKSTART.md`
